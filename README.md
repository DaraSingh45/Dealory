# Dealory — Luxury Picks for Everyday Living 

**Live Project:** [dealory.in](https://dealory.in)  
**Repository:** [DaraSingh45/dealory](https://github.com/DaraSingh45/Dealory)

##  Overview
Dealory is a curated e-commerce frontend application designed to deliver a premium, high-conversion shopping experience. Built as a comprehensive personal project, it serves as a showcase of my frontend development skills, UI/UX design sensibilities, and understanding of modern web architectures. 

> ** The "Real-World" Mechanic:** To simulate a fully operational e-commerce business without the overhead of physical inventory, supply chain, or logistics, Dealory employs an **affiliate-style redirection model**. Users browse a custom-built, high-quality frontend, and upon deciding to purchase, are seamlessly redirected to Amazon for fulfillment. This demonstrates not only technical execution but also practical business problem-solving.

---

##  Key Features
- **Curated Collections:** Dynamic categories spanning *Fashion, Shoes, Electronics, Beauty,* and *Health*.
- **Dynamic Product Rendering:** Distinct landing page sections for *Featured*, *Trending*, *New Arrivals*, and *Top Rated* items.
- **Seamless Redirection Engine:** "View Details" functionality safely routes users to external fulfillment pages (Amazon) while maintaining session context.
- **Modern UI Aesthetics:** Utilizes intentional whitespace, clean typography, and smooth hover states to create a premium, trustworthy feel.
- **Fully Responsive:** Mobile-first approach guaranteeing an optimized experience on all screen sizes.
